As an ES module

This page does not use a global Celestial; it loads build/celestial.mjs with import. The same form works in a bundler (webpack, Vite, Rollup) and in Node too — this is what upstream #141, #115, #86 and #81 are about. 

import Celestial from "../build/celestial.mjs";
Celestial.display({ container: "celestial-map", ... });
